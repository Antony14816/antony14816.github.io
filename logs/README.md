# logs/ — 開発ログ

このリポジトリは **GitHubでpublic公開** です。ここに書く内容は全世界から見えます。
作業ごと・セッションごとに `YYYY-MM-DD.md`（1日1ファイル、追記式）へ記録します。

## 書いてよいこと

- 実装内容、判断理由、変更したファイル、実行したコマンドとテスト結果
- 「確認済み」と「未検証」の区別（推測を断定しない）
- 公開情報: 公開IssueのURL、公開APIの仕様、CC BY 4+ の作品情報、料金表の引用元

## 書いてはいけないこと

- **APIキー・トークン・パスワードの一切**（`.env` の内容、`GH_TOKEN` / `PROTOPEDIA_API_V2_TOKEN` /
  `AI_API_KEY` の値。**マスク表示や先頭部分だけの断片も含む**）
- GitHub Secrets の値、ローカル環境の認証情報を含むコマンド出力（貼る前に必ず確認する）
- 個人情報（本名・メールアドレス・所在地・連絡先）、非公開のやり取りの引用
- 他人の非公開情報、未公開の仕様、社外で共有すべき内容

> 安全側に倒す: 機密かどうか迷ったら書かない。Issueや口頭で補足する。

## 形式（1日1ファイル）

```markdown
# 開発ログ YYYY-MM-DD

## <作業テーマ>
- 実装したこと / 判断理由
- 実行した検証（コマンドと結果の要点）

## 未検証 / 次の作業
- 追い確認が必要なこと、次にやること
```
