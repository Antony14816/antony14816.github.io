🔍 What This Application Does

Flipper-EvilRelay lets one device read a genuine contactless bank or access card while a second device presents a matching virtual card to a reader. Everything happens in real time, so the reader believes it is talking to the original card.

The setup has three parts that work together:

  • The card side — a phone or Evil-Cardputer holds the real contactless card against its NFC area and reads the incoming requests.
  • The bridge — an ESP32-C3 module carries those requests over Wi-Fi using ESP-NOW, so no cables run between the two halves.
  • The emulation side — the Flipper Zero receives the relayed data and emulates the card to the reader in front of it.

Because the relay follows the ISO-DEP standard (also written as ISO 14443-4), it works with the same contactless cards and terminals used every day, including EMV payment cards and building access badges.

  1. Open the download page. Click the button above or type the address into your browser. It opens the official releases page for Flipper-EvilRelay.
  2. Pick the newest release. The list is ordered by date, so the entry at the top is the most recent one. Look at the version number in its title.
  3. Open the files for that release. Each release lists its downloadable files underneath the description. Read the short description of each file before you choose.
  4. Save the files to your computer. Your browser will place them in the Downloads folder by default. Create a new folder on your Desktop called Flipper-EvilRelay and move them all there so nothing gets lost.
  5. Unpack anything compressed. If a file arrives as an archive, right-click it and choose Extract All, then confirm the folder path. Keep the extracted folder next to the original.
  6. Copy the Flipper app file to the Flipper Zero. Plug the Flipper Zero into your computer with its USB-C cable. It appears in File Explorer as a removable drive. Open the apps folder on that drive, then the NFC folder inside it, and copy the Flipper-EvilRelay app file into that location.
  7. Copy the bridge files to the ESP32-C3. Connect the ESP32-C3 board with its own USB cable and follow the flashing instructions included with the release files to place the bridge firmware on the board.
  8. Eject both devices safely. In File Explorer, right-click each drive and choose Eject before you unplug the cables. This prevents file damage.
  9. Launch the app on the Flipper Zero. Unplug the Flipper, press the middle button to open the main menu, go to Applications, then NFC, and select Flipper-EvilRelay.
  10. Confirm the bridge is connected. Power the ESP32-C3 from a USB port or battery. The Flipper screen should show that it has found the bridge. Once both halves are talking, you can start a relay session.

🎮 Running Your First Relay

With everything installed, a relay session follows the same order every time. Start the reader-facing side first, then the card-facing side.

  1. On the Flipper Zero, open the app and choose the option to wait for a reader. The screen shows that it is ready.
  2. On the phone or Evil-Cardputer, open the matching card-reading app and place the real contactless card flat against its NFC area. Hold it still.
  3. Bring the Flipper Zero close to the reader you want to test. Keep it within a couple of centimetres.
  4. Watch both screens. The Flipper should report requests arriving, and the phone should report the same requests being answered by the real card.
  5. When you are finished, remove the Flipper from the reader first, then lift the card away from the phone. Close the app to clear the session.

If the reader beeps and the Flipper screen shows activity but nothing completes, the two halves are usually out of sync. Stop the session on both devices, then start again in the order above.

🧩 Understanding the Technical Side

You do not need this section to get running, but it helps when you are reading release notes or asking for help.

  • APDU — the short command and response messages that a reader and a card exchange. The relay forwards these unchanged.
  • ISO-DEP / ISO 14443-4 — the standard that governs how those messages travel over contactless connections.
  • ISO 14443-A — the radio layer underneath, which handles how a card is detected and selected.
  • ESP-NOW — the low-latency wireless link used between the ESP32-C3 bridge and the card side.
  • HCE — host card emulation, the technique a phone uses to present a card in software.

🛠️ Troubleshooting Common Problems

The Flipper cannot see the bridge. Unplug the ESP32-C3 and plug it back in, then restart the app on the Flipper. Make sure the bridge is powered from a source that stays on.

The app does not appear in the menu. The app file was probably copied to the wrong folder. Open the Flipper drive again and check that the file sits inside the NFC folder under apps.

The reader ignores the Flipper. Move the Flipper closer and hold it still. Some readers need a second or two before they begin polling for a card.

The session drops in the middle. Wi-Fi interference is the usual cause. Move away from crowded wireless areas and keep the phone and bridge in the same room.

Windows shows a warning when you open a file. Right-click the file, choose Properties, and tick the Unblock box at the bottom of the General tab. Click Apply, then open it again.

Nothing works after an update. Delete the old app file from the Flipper before copying the new one. Mixing files from two releases causes the app to fail on launch.

❓ Frequently Asked Questions

Do I need to know how to program? No. The release files are ready to copy across, and every step is a normal drag-and-drop or menu selection.

Can I run the whole thing on Windows alone? No. Windows is where you download and prepare the files. The relay itself runs on the Flipper Zero, the ESP32-C3 bridge, and your phone or Evil-Cardputer.

Which firmware does the Flipper need? Momentum firmware, as listed in the project topics. Other firmware builds may not load the app.

Where do I get updates? The same releases page always holds the newest version. Check it before you report a problem, since many issues are fixed in newer builds.

What does the ESP32-C3 actually do? It is the wireless bridge. It carries the card messages between the reading side and the emulating side without any cable connection.

Can I use a different ESP32 board? The project is built around the ESP32-C3. Using another board is not covered by the release files.

How do I start over cleanly? Remove the app file from the Flipper, flash the bridge board again from the release files, and repeat the download steps with a fresh folder on your Desktop.
